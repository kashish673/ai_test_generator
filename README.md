🙂About Project:
In the modern digital era, education is evolving with the integration of advanced technologies such as Artificial Intelligence (AI). One of the key applications of AI in education is the automation of assessment creation.

The **AI-Powered Test Generator** is a full-stack web-based platform that generates different types of test questions including:

- Multiple Choice Questions (MCQs)
- Theoretical Questions
- Descriptive Questions

The system dynamically generates questions using AI models based on the user's input parameters.

🙂Features:
✔ Topic-Based Question Generation  
✔ Difficulty-Based Customization  
✔ Multiple Question Types (MCQs, Theory, Descriptive)  
✔ AI-Powered Dynamic Content Generation  
✔ User Authentication (Sign-Up / Sign-In)  
✔ Interactive Web Interface  
✔ Backend API Integration  
✔ Instant Test Generation

🙂Architecture:
The system follows a **Client-Server Architecture**:
1. User inputs topic, difficulty level, and number of questions.
2. Frontend sends request to backend server.
3. Backend communicates with AI API.
4. AI model generates questions.
5. Generated questions are sent back to frontend.
6. Questions are displayed to the user.
